# Инструкции для Claude

## Перед началом работы

1. Прочитай `CONTEXT.md` и `README.md`.
2. Просмотри `index.md`, `sources.md` и `decisions.md`, чтобы не дублировать уже найденное и не возвращаться к отброшенным идеям.

## Поиск идей

- Ищи в источниках из `README.md`. Предпочитай свежие материалы (последние 12–18 месяцев).
- Идея принимается только с доказательствами: минимум 2 ссылки на реальные жалобы, запросы или платных конкурентов. Без ссылок идею не добавляй.
- Перед созданием карточки проверь, нет ли похожей идеи в `index.md`. Если есть, дополни существующую карточку новыми ссылками.
- Каждый поисковый проход записывай в `sources.md`: дата, источник, запросы, сколько идей найдено.

## Карточки идей

- Создавай по шаблону `templates/idea.md` в `ideas/NNN-slug.md`. NNN — следующий свободный номер с ведущими нулями, slug — латиницей через дефис.
- Оценки ставь по шкале из `README.md` и коротко обосновывай каждую. Если данных для оценки нет, ставь `?`, а не угадывай.
- Цены конкурентов указывай только проверенные, со ссылкой.
- Новым идеям ставь статус `scored`, если все критерии оценены, иначе `new`.

## Сводная таблица

После любых изменений в карточках обнови `index.md`: строки отсортированы по сумме баллов по убыванию, неоценённые внизу.

## Решения

- Не переводи идеи в `shortlist`, `selected` или `rejected` по своей инициативе. Это решает владелец. Можешь предлагать в отчёте.
- Исключение: стоп-правило из `README.md`. Такие идеи можно сразу помечать `rejected` с записью причины в `decisions.md`.

## Коммиты

- Один логический шаг на коммит.
- Сообщения на русском в формате: `ideas: добавлено 5 идей из r/selfhosted`, `score: оценка 004`, `index: обновлена таблица`, `sources: проход по G2`.
- Не переписывай историю и не делай force push.

## Отчёт в конце сессии

Кратко: что сделано, сколько идей добавлено или изменено, топ-3 по баллам, что предлагаешь сделать дальше.
