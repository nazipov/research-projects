# 021. Отправка вебхуков для маленьких SaaS (дешёвый Svix)

## Проблема

SaaS-продуктам нужно надёжно отправлять вебхуки клиентам: ретраи, подписи, логи, портал для клиентов. Svix стоит $100 за миллион событий, Hookdeck — от $39/мес; дешёвый Hookdeck Outpost ($10 за миллион) жертвует функциями и надёжностью.

## Целевая аудитория

Маленькие B2B SaaS, которым клиенты начинают требовать вебхуки.

## Почему это больно

Самописная очередь вебхуков — недели работы и постоянные инциденты; готовые сервисы дороги на объёмах.

## Как решают сейчас

- Svix, Hookdeck (Outpost), Hook0, Convoy (open source)
- Самописные очереди

## Доказательства

- [DEV: Svix vs Hookdeck vs QStash для инди (2026)](https://dev.to/devtoolpicks/svix-vs-hookdeck-vs-qstash-for-indie-hackers-in-2026-2gb7): сравнение цен для небольших проектов.
- [Hookdeck: Svix alternatives](https://hookdeck.com/webhooks/platforms/svix-dispatch-alternatives): Outpost $10 против $100 за миллион событий у Svix (материал конкурента).
- [Svix: alternatives to Hook0](https://svix.com/alternatives/hook0/): у Convoy компания больше не активна, Hook0 — только EU-хостинг (материал конкурента).

## Идея решения

Простой API отправки + портал для клиентов + плоская цена до N событий.

## Монетизация

$19–99/мес. $10k MRR ≈ 150–500 клиентов.

## Риски и открытые вопросы

- Ниша переполнена, лидеры дешевеют.
- Высокие требования к надёжности для соло-разработчика.

## Заметки

Высокий балл держится на соответствии навыкам, а не на пробеле в рынке.
