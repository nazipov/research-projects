# 007. Мобильная панель для серверов и homelab (статус, алерты, виджеты)

## Проблема

Владельцы VPS и домашних лабораторий держат Proxmox, Docker, Uptime Kuma, TrueNAS и хотят видеть их состояние с телефона: виджет на экране, пуш при падении, быстрый перезапуск контейнера. Сейчас для этого нужно несколько разных приложений, по одному на каждый сервис.

## Как решают сейчас

- ServerCat, ServerBox — общие метрики серверов по SSH.
- Узкие приложения: KumaAlert и Uptime Kuma Manager (Uptime Kuma), ProxMate, HomeLab Go, ProxmoxR, ProxMan (Proxmox).
- Веб-интерфейсы в мобильном браузере.

## Доказательства

- [App Store: ServerCat](https://apps.apple.com/us/app/servercat/id1501532023): мониторинг бесплатно; Premium $5.99/год или $18.99 навсегда (SSH, синхронизация, управление контейнерами).
- [App Store: KumaAlert](https://apps.apple.com/gb/app/kumaalert/id6760863575): платное iOS-приложение только для мониторинга Uptime Kuma.
- [App Store: Uptime Kuma Manager](https://apps.apple.com/app/id6446004887): бесплатно со встроенными покупками.
- [Lemmy: какое приложение для мониторинга homelab с iPhone](https://lemmy.world/post/47600208): пользователи ищут и сравнивают ServerBox, OpsHome NOC и другие.
- [ProxmoxR](https://proxmoxr.com/): кроссплатформенное приложение для Proxmox с 7-дневным пробным периодом.

## Идея решения

Одно приложение с плагинами для популярных сервисов: Proxmox, Docker/Portainer, Uptime Kuma, TrueNAS. Виджеты и пуши без собственного сервера (опрос через лёгкий агент или Tailscale). Модель: бесплатно 1 сервер, разовая покупка или недорогая подписка. Можно связать с идеями 001 и 003: пуши от собственных SaaS-мониторов.

## Риски и открытые вопросы

- Аудитория любит open source и бесплатное; готовность платить низкая.
- Ниша дробится: у каждого сервиса уже есть своё приложение.
- Пуши на iOS без сервера невозможны — нужна собственная инфраструктура рассылки.
