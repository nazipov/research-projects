# 032. Архив истории для сообществ на бесплатном Slack

## Проблема

На бесплатном Slack сообщения старше 90 дней скрыты; сообщества и маленькие команды теряют историю обсуждений, а платный Slack стоит от $8.75 за пользователя в месяц.

## Целевая аудитория

Open source и профессиональные сообщества, маленькие команды на бесплатном Slack.

## Почему это больно

Знания из обсуждений пропадают; для сообщества на 1,000 участников платный Slack нереален.

## Как решают сейчас

- slackdump (open source), slack-export-viewer, ручной экспорт
- Переезд в Discord, Zulip

## Доказательства

- [GitHub: slackdump](https://github.com/rusq/slackdump): инструмент прямо называет сценарий «архивировать каналы на бесплатной подписке без архива».
- [GitHub: slack-export-viewer](https://github.com/dvii7/slack-export-viewer/blob/master/README.md): для маленьких команд на бесплатном Slack, которым нужна старая переписка.
- [Pebb: Slack 90-day restriction](https://pebb.io/blog/slack-s-90-day-message-history-restriction-what-you-can-do-about-it): сообщения старше 90 дней недоступны без платного тарифа (блог конкурента).

## Идея решения

Бот, который непрерывно сохраняет сообщения и делает поисковый (по желанию — публичный) архив.

## Монетизация

$9–29/мес за сообщество.

## Риски и открытые вопросы

- Slack может ограничить API для приложений вне Marketplace — проверить текущие лимиты.
- Бесплатные инструменты закрывают задачу для технических админов.
