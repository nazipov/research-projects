# 036. Простой API индексов растительности (NDVI) по полигонам для небольших агро- и гео-команд

## Проблема

Разработчикам агро-приложений, страховых и консалтинговых сервисов нужен временной ряд NDVI/NDWI, облачность и снимок по полигону поля. Сырые данные Sentinel-2 бесплатны, но обработка (STAC-поиск, маски облаков, обрезка COG, кэш) требует ГИС-экспертизы. Google Earth Engine для коммерческого использования стоит от $500/мес на тарифе Basic.

## Целевая аудитория

Небольшие агротех-стартапы, разработчики фермерских приложений, агрономы-консультанты, страховые и кредитные стартапы в развивающихся рынках.

## Почему это больно

Переход с бесплатного академического Earth Engine на коммерческий бьёт по бюджету малых команд; свой конвейер обработки — недели работы и постоянная поддержка.

## Как решают сейчас

- AgroMonitoring (OpenWeather): Free до 1 000 га, Starter £20/мес до 4 000 га, Small Kit £200/мес.
- Sentinel Hub (Planet), в том числе бесплатная квота в Copernicus Data Space.
- Earth Engine: Basic $500/мес, Professional $2 000/мес или тариф Limited с оплатой только за использование.
- Свой конвейер на открытых данных AWS (Earth Search STAC).

## Доказательства

- [Google Earth Engine pricing](https://cloud.google.com/earth-engine/pricing): Basic $500/мес, Professional $2 000/мес, Limited — только оплата за использование, 1 разработчик, без SLA.
- [FitGap: Earth Engine](https://us.fitgap.com/products/google-earth-engine): переход на коммерческую лицензию — проблема для стартапов и малых организаций (вторичный источник).
- [AgroMonitoring: цены](https://agromonitoring.com/price): £0 / £20 / £200 в мес. за 1 000 / 4 000 / 20 000 га.
- [Sentinel Hub FAQ](https://www.sentinel-hub.com/faq/how-can-i-know-how-many-processing-units-i-need/): тарифы по processing units (Exploration 30 000 PU/мес, Basic 70 000), batch API только на Enterprise.
- [KI-Syndikat: Copernicus Data Space](https://www.ki-syndikat.de/tools/copernicus-data-space/): бесплатно 10 000 PU и 12 ТБ трафика в месяц (вторичный источник).

## Идея решения

REST API: POST полигона → временной ряд индексов, процент облаков, PNG/GeoTIFF превью, вебхук при новом безоблачном снимке. Данные с открытого бакета Sentinel-2 на AWS (без платы за трафик внутри региона), обработка лениво по запросу с кэшем. Отличие — простая цена «за гектар в месяц» без PU и вебхуки.

## Монетизация

Бесплатно до 100 га, далее $19–199/мес по гектарам. Путь к $10k MRR: 100–200 платящих команд. Инфраструктура: вычисления в том же регионе AWS, до $200/мес на старте.

## Риски и открытые вопросы

- Конкуренция с бесплатной квотой CDSE и дешёвым AgroMonitoring — ценой не выиграть, только удобством.
- Ценность только для разработчиков; фермеры берут готовые приложения (OneSoil бесплатно).
- Не найдено ни одной прямой жалобы на AgroMonitoring или Sentinel Hub — нужен проход по r/gis и форуму Sentinel Hub.
