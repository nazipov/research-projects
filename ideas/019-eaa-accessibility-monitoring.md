# 019. Мониторинг доступности сайтов (WCAG) для малых магазинов под Европейский акт о доступности

## Проблема

С 28.06.2025 действует European Accessibility Act: магазины, продающие в ЕС, должны соответствовать WCAG 2.1 AA. Популярные overlay-виджеты не решают задачу: в 2025 FTC оштрафовала accessiBe на $1 млн за ложные обещания «автоматического соответствия». Малым магазинам нужен честный и недорогой способ найти и исправить проблемы.

## Целевая аудитория

Малые интернет-магазины (Shopify, WooCommerce), продающие в ЕС; веб-агентства, которые их обслуживают.

## Почему это больно

Штрафы устанавливает каждая страна ЕС отдельно; переделка сайта после жалобы дороже, чем постоянный контроль.

## Как решают сейчас

- Overlay-виджеты (accessiBe, UserWay) — дискредитированы
- Сканеры: ACE, Access Radar, Accessible Web RAMP, Silktide, Siteimprove
- Ручной аудит у специалистов

## Доказательства

- [OECD.AI: FTC fines accessiBe $1M](https://oecd.ai/en/incidents/2025-01-03-e129): штраф за ложные заявления об автоматическом соответствии WCAG.
- [Fudge.ai: EAA для Shopify-магазинов (2026)](https://www.fudge.ai/blog/european-accessibility-act-shopify/): более 1,000 специалистов подписали заявление, что overlay не обеспечивают соответствия; штрафы задаёт каждая страна.
- [accessiBe: EAA compliance impact for ecommerce](https://accessibe.com/industry-reports/eaa-uk-compliance-impact-for-ecommerce): EAA вступил в силу 28.06.2025 (материал вендора).
- [Capterra: ACE Scanner](https://www.capterra.com/p/10046645/ACE/): платные сканеры $89–299/мес.

## Идея решения

Shopify-приложение и веб-сервис: еженедельный скан магазина, понятные инструкции по исправлению для конкретной темы Shopify, отчёт для юриста. Без overlay.

## Монетизация

$19–49/мес за магазин, $99+ для агентств. $10k MRR ≈ 250–500 клиентов.

## Риски и открытые вопросы

- Автоматический скан ловит только около трети критериев WCAG — нельзя обещать «соответствие».
- Конкурентов много, нужен канал (Shopify App Store).
- Краулинг больших магазинов может выйти за $200/мес инфраструктуры.
